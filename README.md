# 🤖 Mikis13 AI Robots
[![Build APK](https://github.com/Ice1984m/mikis13-ai-robots/actions/workflows/build-apk.yml/badge.svg)](https://github.com/Ice1984m/mikis13-ai-robots/actions/workflows/build-apk.yml)

Vijf lokale botkamers voor toegestane GitHub issue-, bug-, test-, review- en releasewerkzaamheden.

## Start
```bash
npm install && npm install -g pm2
./start.sh
```
Dashboard: `http://127.0.0.1:4700`

## Gratis lokale AI
```bash
./install-local-ai.sh
```
Plaats daarna zelf een geschikt GGUF-model in `~/models/model.gguf` en start `llama-server` zoals het script aangeeft.
